# TensorFlow

> TensorFlow is an end-to-end open source machine learning platform developed by Google. It provides tools, libraries, and community resources for building and deploying ML-powered applications, including model training, serving, mobile/edge deployment, and a hub of pre-trained models. TensorFlow Serving exposes REST and gRPC APIs for production model inference.

This file was generated by API Evangelist from the apis.yml catalog and repo artifacts (no upstream llms.txt was published at www.tensorflow.org as of 2026-06-20).

## APIs

- [TensorFlow Serving REST API](https://www.tensorflow.org/tfx/serving/api_rest): REST endpoints for model status, metadata, classification, regression, and prediction inference.
- [TensorFlow Core API](https://www.tensorflow.org/api_docs/python/tf): Foundational Python/C++ API for building and training models.
- [TensorFlow.js API](https://js.tensorflow.org/api/latest/): JavaScript library for training and deploying ML models in the browser and Node.js.
- [TensorFlow Lite API](https://www.tensorflow.org/lite/api_docs): On-device ML inference for mobile and embedded devices.
- [TensorFlow Hub API](https://www.tensorflow.org/hub/api_docs/python/hub): Library and repository of reusable pre-trained ML modules.
- [TensorBoard API](https://www.tensorflow.org/tensorboard/get_started): Visualization toolkit for experiment tracking and model debugging.
